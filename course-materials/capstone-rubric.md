# Capstone Rubric

The capstone (Module 7 / Lab 07) asks each participant to design, build, and demo an
AI-assisted solution for a real challenge from their own work. Score it out of 30.

| Criterion (1–5) | Strong (5) | Needs work (1–2) |
|-----------------|------------|-------------------|
| **Business fit** | Solves a real, recurring, worth-it workflow problem | Vague or low-value use case |
| **Prompt quality** | Uses the anatomy; clear role, task, context, constraints, format | Ambiguous, thin prompt |
| **Technique fit** | Right tool for the job — chaining/reasoning/grounding used only where they earn it | Over- or under-engineered |
| **Output quality** | Deliverable is usable with light review; scored on the rubric | Needs major rework |
| **Safety & judgment** | Source boundaries, privacy, verification, and "when not to use AI" built in | Risks unaddressed |
| **Rollout plan** | Concrete 30-day plan; prompt is documented for reuse by others | No path to adoption |

**Total: ___ / 30**

## What a strong capstone demonstrates

- A prompt (or prompt chain) that someone else on the team could run and get the same result.
- A **before/after**: the manual way vs. the AI-assisted way, with the time or quality gain named.
- At least one **guardrail** the presenter deliberately added (source boundary, human review
  step, privacy rule) and can explain.
- Honesty about limits: where it still needs a human, and the review step that stays.
