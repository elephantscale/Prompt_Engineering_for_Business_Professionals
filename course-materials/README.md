# Course Materials

Reusable classroom assets for **Prompt Engineering for Business Professionals**.

| File | Use |
|------|-----|
| `prompt-template.md` | The reusable R-T-C-C-F-E prompt shape; used in every lab from Module 2 on |
| `prompt-anatomy-cheatsheet.md` | One-page reference: building blocks, verbs, and the five failure modes |
| `brand-voice-worksheet.md` | Capture your organization's voice so drafts come back on-brand (Lab 03) |
| `evaluation-rubric.md` | Score AI output 1–5 across 8 criteria; used in Lab 05 and the capstone |
| `prompt-library-template.md` | Entry format for a reusable, versioned team prompt library (Lab 06) |
| `capstone-rubric.md` | Capstone scoring and feedback guide (Lab 07) |
| `cohort-intros.html` | Self-contained "introduce yourself" form — students fill it in, copy the generated card, and paste it into the class chat. No account, nothing is sent anywhere. |

## Cohort intro form

`cohort-intros.html` is a single self-contained page (no build step, no backend). Two ways
to use it:

- **Local:** download the file and open it in any browser.
- **Hosted (GitHub Pages):** share this link —
  `https://elephantscale.github.io/Prompt_Engineering_for_Business_Professionals/course-materials/cohort-intros.html`
  (or the course landing page: `https://elephantscale.github.io/Prompt_Engineering_for_Business_Professionals/`).
