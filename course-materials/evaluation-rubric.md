# Prompt Output Evaluation Rubric

Use this to score AI output the same way twice, so "good" is a number you can defend, not a
feeling. Score each criterion 1–5. Use it to compare two prompts (Lab 05), to grade your own
iterations (Module 5), and as the quality bar in the capstone.

| Criterion (1–5) | 1 — poor | 3 — usable | 5 — excellent |
|---|---|---|---|
| **Accuracy** | Contains wrong facts | Mostly right, minor slips | Every claim checks out against the source |
| **Completeness** | Misses parts of the ask | Covers the main asks | Covers every requested item |
| **Format compliance** | Ignores requested format | Close, needs tidying | Exactly the format asked, paste-ready |
| **Source handling** | Invents beyond the source | Mostly stays in source | Stays in source; says "not in the source" when true |
| **Tone / brand fit** | Off-brand or wrong register | Acceptable | Matches the target voice |
| **Uncertainty honesty** | Bluffs confidently | Some hedging | Flags what's uncertain or missing |
| **Reusability** | One-off, unusable again | Reusable with edits | Ready to paste and reuse as-is |
| **Review burden** | Major rework needed | Light edit needed | Ship with a glance |

**Total: ___ / 40**

## How to use it

1. Write the prompt. Run it. Score the output.
2. Change **one** thing in the prompt. Run again. Score again.
3. Keep the version with the higher total. Note *which clause* moved the score — that's the
   reusable lesson.

## Scoring rules that keep you honest

- **Check accuracy against the source, not against how fluent it sounds.** Fluent ≠ correct.
- A confident invented statistic is a **point off Uncertainty and Accuracy**, not a bonus.
- "I liked it more" is not a score. Every number needs a one-line reason.
- Two outputs that differ wildly usually mean memory/custom-instructions were on, or the
  prompt was ambiguous — fix that before you trust the comparison.

## Quick decision line

> Ship it if: total ≥ 32, **and** Accuracy and Source handling are both ≥ 4.
> Otherwise iterate — the rubric tells you which clause to add next.
